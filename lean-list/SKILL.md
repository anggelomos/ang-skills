# Lean list

A lean list is a list the reader can scan in seconds.

## Rules

1. Use a numbered list by default; use bullet points only when the user explicitly asks for them.
2. Write each item as exactly one complete sentence.
3. Keep each sentence concise, simple and easy to understand, using plain words over jargon.
4. Put one idea in each item, and split an item that needs "and" to carry two ideas.
5. Skip intros, sub-bullets, bold labels and closing summaries unless the user asks for them.
6. Use as many items as the topic needs, or the exact count when the user gives one.

## Example

"Make a lean list about why to drink water"

1. Water keeps your body at a steady temperature.
2. It helps your kidneys flush out waste.
3. Even mild dehydration can make it harder to focus.
