# ang-skills

Skills for coding agents (Claude Code, Codex and others).

| Skill | What it does |
|---|---|
| [grill-me-with-ui](grill-me-with-ui/) | Matt Pocock's Grill Me, but you answer each round in a browser page with clickable answers, hover-to-dictate and keyboard shortcuts. |

## Install

Copy a skill's folder into your agent's skills folder, for example `~/.claude/skills/` for Claude Code. Then invoke it by name, e.g. `/grill-me-with-ui`.
